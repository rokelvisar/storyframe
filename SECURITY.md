# Security policy

If you find a security issue (something that could leak data, execute
arbitrary code, or bypass an intended access control), please **don't** open
a public GitHub issue for it. Instead, report it privately via GitHub's
[private vulnerability reporting](../../security/advisories/new) for this
repo, or open a regular issue asking for a private channel if that's not
available.

Please include:
- What you found and why it's exploitable
- Steps to reproduce, if possible
- Which version/commit you tested against

There's no bug bounty here — this is a small side project — but reports are
genuinely appreciated and will get a real response.
